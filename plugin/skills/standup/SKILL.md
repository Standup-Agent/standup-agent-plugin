# Standup Agent: рабочие и личные репо

В стендап попадает работа только из репо, помеченных как **рабочие**. Личные и неразмеченные репо не сохраняются даже локально. Менеджер видит только стендапы, которые разработчик сам подтвердил; код, чаты и личные репо не покидают компьютер.

Все команды ниже выполняй через Bash ровно в таком виде — путь к данным плагина в окружении Bash не передаётся. Каждая печатает JSON.

- Список разметки: `CLAUDE_PLUGIN_DATA="${CLAUDE_PLUGIN_DATA}" node "${CLAUDE_PLUGIN_ROOT}/dist/cli.js" repos list`
- Скан репо за 30 дней: `CLAUDE_PLUGIN_DATA="${CLAUDE_PLUGIN_DATA}" node "${CLAUDE_PLUGIN_ROOT}/dist/cli.js" repos scan`
- Разметить: `CLAUDE_PLUGIN_DATA="${CLAUDE_PLUGIN_DATA}" node "${CLAUDE_PLUGIN_ROOT}/dist/cli.js" repos set '<path>=work' '<path>=personal' …` (путь — абсолютный, как в выводе скана; одним вызовом можно разметить несколько)

## Первичная разметка (после вступления в команду или `/standup repos scan`)

1. Выполни `repos scan`. Репо из организации команды (`auto_marked_work`) скан уже включил сам — их не спрашивай.
2. Одним сообщением: «Нашёл N репо, где ты работал за месяц. K из организации команды, их я включил: …». Если `ask` пуст — на этом всё.
3. Про репо из `ask` спроси **один раз и на одном экране**:
   - до 4 репо — AskUserQuestion с `multiSelect: true`: вопрос «Какие из этих репо рабочие? Невыбранные будут личными», header «Репо», опция на каждое репо (label — имя репо, description — remote и дата последней активности);
   - больше 4 — нумерованным списком текстом (имя, remote, последняя активность) и попроси ответить номерами рабочих; остальные будут личными.
4. Одной командой `repos set` запиши выбранные как `work`, остальные из `ask` как `personal`. Если пользователь отказался отвечать — ничего не записывай.
5. В ответе `backfill_sessions` — сколько сессий за последние 3 дня дособирается в фоне для первого стендапа. Коротко подтверди: что включено, что нет, и что поменять можно через `/standup repos`.

## Просмотр и правка (`/standup repos` без `scan`, «выключи репо X»)

Здесь **не запускай** `repos scan` и не опрашивай про неразмеченные репо — только показ и правка. Выполни `repos list` и покажи разметку коротко: рабочие, потом личные (по имени папки, путь — если имена совпадают). В конце одной строкой: «Разметить остальные репо, где ты работал за месяц: /standup repos scan». Если пользователь просит поменять — `repos set` с нужными путями и подтверди одной строкой. Новое рабочее репо сразу дособирает последние 3 дня.
